## Open source

### TypeWire

**Typed contracts. Any transport.**

TypeWire is the open-source project I’m currently most focused on.

The goal is simple: define your contracts once and use them across your application without losing type safety between the client and server.

The ecosystem currently includes:

* `@tahanabavi/typefetch` — typed HTTP client powered by Zod contracts
* `@tahanabavi/typesocket` — typed Socket.IO communication
* `@tahanabavi/typewire-cli` — CLI tooling for reports, releases and documentation
* Contract validation
* Mock data
* Middleware
* Retries
* Contract testing
* Token providers

[Explore TypeWire →](https://typewire.tahanabavi.ir)
